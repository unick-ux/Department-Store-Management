# 🏪 Department Store Management System

A console-based **Department Store Management System written in C**.

📌 Features

- Add, display, search, update, and delete products
- Inventory management
- Low-stock detection
- Shopping cart system
- Add and remove products from cart
- Generate bills
- Automatic stock deduction after sales
- 5% discount on purchases of 5000 or more
- 5% tax calculation
- Sales report
- Automatic bill numbering
- Date and time on bills
- File handling for persistent data storage
- Input validation

🛠️ Technologies

- C Programming Language
- Structures
- Arrays
- Functions
- File Handling
- String Handling
- Pointers
- Date and Time
